# 📘 OOPJ Basic Programs (Java)

This repository contains a collection of **basic Object-Oriented Programming in Java (OOPJ)** programs covering fundamental concepts. It is designed for beginners to understand core Java principles with simple examples.

---

## 📌 Topics Covered

### 🔁 Loops

Programs demonstrating different looping constructs:

* `for` loop
* `while` loop
* `do-while` loop
* Nested loops
* Pattern printing

---

### 🔄 Method Overloading

Examples showing:

* Same method name with different parameters
* Compile-time polymorphism
* Different data types and argument lists

---

### 🔁 Method Overriding

Programs covering:

* Inheritance
* Runtime polymorphism
* Use of `@Override` annotation
* Dynamic method dispatch

---

### ⚠️ Exception Handling

Examples demonstrating:

* `try`, `catch`, `finally` blocks
* Multiple catch blocks
* `throw` and `throws` keywords
* Handling runtime exceptions

---

### 🔤 Strings

Programs based on:

* String creation and manipulation
* String methods (`length()`, `substring()`, `compareTo()`, etc.)
* StringBuffer and StringBuilder basics

---

### 📂 I/O Streams

Examples covering:

* File handling in Java
* File input and output streams
* Reading and writing data
* Buffered streams

---

### 🧵 Multithreading

Programs demonstrating:

* Creating threads using `Thread` class
* Implementing `Runnable` interface
* Thread lifecycle
* Synchronization basics

---

## 🚀 How to Run

1. Clone the repository:

```bash
git clone https://github.com/your-username/oopj-basic-programs.git
```

2. Navigate to the project folder:

```bash
cd oopj-basic-programs
```

3. Compile the Java file:

```bash
javac FileName.java
```

4. Run the program:

```bash
java FileName
```
